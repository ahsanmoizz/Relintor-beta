## Product sentence

> Relintor is the execution and verification layer for AI-built software. It converts human intent into a sealed, traceable project contract; governs Antigravity execution; independently verifies evidence; and refuses to call work complete while any required outcome is missing, failed, blocked, or unproven.

## Non-negotiable product rule

**The coding agent never owns the word `DONE`. Relintor does.**

## Platform baseline

The first full Antigravity release targets:
- Windows 10 64-bit and newer
- supported macOS versions, minimum matching Antigravity's supported baseline
- Linux distributions meeting Antigravity's current runtime requirements

Windows 7 is intentionally excluded because Antigravity itself does not support it.

## Engineering philosophy

This is not an MVP specification. It is a complete Antigravity-first product boundary. “Full” means every promise in the boundary is closed end-to-end and tested. It does **not** mean adding unrelated IDEs or enterprise features that do not strengthen the core promise.
